# 🏢 AI OFFICE — 2D 가상 오피스 대시보드 (v1)

부서별 AI 직원이 자리한 **2D 가상 오피스**입니다. 업무를 요청하면 비서실이 회의를 소집하고,
참여 직원들이 미팅룸으로 걸어가 역할별로 발언한 뒤, 결정사항과 다음 액션이 담긴
**최종 합의 보고서**를 남깁니다.

- 라이브: <https://inje8451.github.io/ai-office>
- 외부 라이브러리·CDN·유료 에셋 없이 HTML / CSS / JS 만으로 동작합니다.
- 데스크톱과 모바일(아이폰 사파리) 모두에서 사용할 수 있는 반응형 레이아웃입니다.

## 기능

### 1. 오피스 맵
- 부서별 방, 책상·모니터·화이트보드·화분, 미팅룸 테이블과 좌석을 CSS로 직접 그렸습니다.
- 직원 캐릭터는 SVG로 생성하며, 상태에 따라 배지가 바뀝니다. `대기` / `작업 중` / `회의 중`
- 회의가 시작되면 참여 직원이 **부드럽게 미팅룸 좌석으로 이동**하고, 발언 중에는 말풍선과
  강조 표시가 나타납니다. 회의가 끝나면 원래 자리로 돌아갑니다.
- 모바일에서는 방이 세로로 쌓인 **건물 단면도** 형태로 바뀌고, 회의가 시작되면 회의실이
  보이도록 자동으로 스크롤합니다.

### 2. 업무 요청 → 회의
- `+ 업무 요청하기` → 안건 입력 또는 **빠른 프리셋 4종** 선택
  - 📈 장 마감 시황 & 리스크 점검 회의
  - ✍️ 블로그 신규 포스팅 기획 회의
  - 🏙️ 인천 아파트 입지 비교 리포트
  - 🗾 일본 타겟 웹도구 마케팅 회의
- 참여 직원을 직접 고를 수 있고(최대 8명), 프리셋은 주제에 맞는 부서를 자동 선택합니다.
- 진행 순서: 소집 → 역할별 의견 → 리스크·검수 지적 → 응답 → **최종 합의 보고서**
- 회의록은 우측(모바일은 하단) 패널에 실시간으로 쌓이고, 보고서는
  `결정사항 / 근거 / 리스크 및 대응 / 다음 액션(담당·기한)`으로 정리됩니다.
- 여러 건을 요청하면 **대기열**에 쌓이고 순서대로 진행됩니다.

### 3. 두 가지 실행 모드
| 모드 | 설명 |
| --- | --- |
| **시뮬레이션** (기본) | API 키 없이 즉시 동작. 안건 키워드와 참여 직원 역할에 맞춰 다자간 회의를 생성합니다. |
| **실전 API** | `⚙️ API 설정`에서 **OpenAI**(`gpt-4o-mini` 등) 또는 **Anthropic**(`claude-3-5-haiku` 등) 키를 넣으면 실제 모델이 역할별로 발언합니다. |

- 키는 브라우저 `localStorage`에만 저장되며 서버로 전송되지 않습니다.
- 키가 없거나 호출이 실패하면 **자동으로 시뮬레이션으로 전환**하고 안내 토스트를 띄웁니다.
- Anthropic 브라우저 직접 호출을 위해 `anthropic-dangerous-direct-browser-access` 헤더를 사용합니다.

### 4. 직원 상세
- 캐릭터를 누르면 역할, 소속, 상태, 최근 회의 참여 기록과 **시스템 프롬프트**를 볼 수 있습니다.
- 프롬프트는 수정·저장할 수 있고(브라우저에 저장), 기본값으로 되돌릴 수 있습니다.
  수정한 프롬프트는 API 모드에서 그대로 사용됩니다.

### 5. 기록
- 완료된 회의는 최대 24건까지 브라우저에 저장되고, `🗂` 버튼으로 다시 열람할 수 있습니다.
- KPI: 오늘 의뢰 / 진행 중 / 완료 / 대기, 그리고 `작업 중 N명`.

## 파일 구성

```
index.html   화면 구조
styles.css   레이아웃·오피스 맵·반응형 스타일
data.js      부서·직원·방 배치·프리셋·역할별 발언 스크립트
engine.js    주제 감지, 회의 턴 구성, 시뮬레이션 생성, 실제 API 호출
app.js       렌더링, 좌표 배치·이동 애니메이션, 회의 오케스트레이션, 저장
```

## 로컬에서 실행

```bash
cd ai-office
python3 -m http.server 8000
# http://127.0.0.1:8000
```

파일을 직접 열어도(`file://`) 대부분 동작하지만, API 모드는 로컬 서버에서 확인하세요.
